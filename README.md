DESCRIPTION OF THE CODE
The java program we have created checks whether a person qualifies for an internship based on three requirements; 1:Age-must be 18 years and above,Citizenship-must be a Ugandan by nationality,Academic qualification-must have a second class upper CGPA or better.
HOW THE CODE WORKS
public class- creates the java class.
main() is where the program starts running.
scanner is used to receive information entered by the user.
The program sets again="Yes" so that it can process an applicant.
It asks applicant to their age.
It asks whether the applicant is ugandan.
It asks whether they have second class upper GGPA or better.
The program then checks each requirement separately.
If all requirements are met, the applicant qualifies for the internship.
If any requirement is not met, the applicant does not qualify.
